# Born2beRoot Progress Tracker

An interactive progress tracker for the Born2beRoot project at 42 School. This web application helps students track their system administration learning journey through guided tasks and achievements.

## Features

- 📊 **Progress Tracking**: Visual progress bar and statistics
- 🏆 **Achievement System**: Unlock achievements as you complete tasks
- 💾 **Auto-Save**: Your progress is automatically saved locally
- 📱 **Responsive Design**: Works on desktop, tablet, and mobile
- 🎯 **Task Management**: Organized sections with detailed tasks
- ⏱️ **Time Tracking**: Estimated time investment tracking

## Project Sections

1. **Virtual Machine Setup** - Download ISO, create VM, configure basic settings
2. **Debian Installation** - Complete OS installation and configuration
3. **System Configuration** - SSH, firewall, user management, security policies
4. **Monitoring Script** - Create and configure system monitoring automation
5. **Final Steps & Submission** - Testing, signature generation, and project submission
6. **Bonus: WordPress Setup** - Advanced web server configuration (optional)

## Getting Started

1. Open `index.html` in your web browser
2. Click on task sections to expand them
3. Click on individual tasks to mark them as complete
4. Track your progress with the visual indicators and achievements
5. Your progress is automatically saved and will persist between sessions
