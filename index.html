Frequently Asked Questions

What is Born2beRoot project at 42 School?

Born2beRoot is a system administration project that teaches students how to set up and configure a virtual machine with Debian Linux, implement security measures, and create monitoring scripts. It's a fundamental project that introduces 42 students to server administration and Linux system management.

How long does Born2beRoot take to complete?

Most students complete the mandatory requirements in 15-25 hours over 3-5 days, with bonus objectives adding an additional 5-10 hours. The project includes VM setup, Debian installation, user management, SSH configuration, firewall setup, and scripting tasks.

Do I need prior Linux experience for Born2beRoot?

While helpful, prior Linux experience isn't required. This project is designed to teach system administration fundamentals from the ground up. You'll learn VirtualBox, Debian Linux, SSH, UFW firewall, sudo configuration, and bash scripting through hands-on practice.

What tools do I need for the Born2beRoot project?

You'll need VirtualBox (or UTM for Mac), the Debian ISO image, and access to the 42 School evaluation system. Our progress tracker helps you manage all the required tasks including VM configuration, network setup, and security implementation.

How does this progress tracker help with Born2beRoot?

Our interactive tracker breaks down the Born2beRoot project into manageable tasks, tracks your completion progress, provides helpful tips, and ensures you don't miss any requirements for the 42 School evaluation. It includes both mandatory and bonus objectives.
